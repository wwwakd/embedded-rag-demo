# 这个仓库缺了什么，以及为什么

> 这份文档是写给**看仓库的人**的。项目来自企业环境，生产版本涉及项目资料与内部规范，
> 不能公开；这里把"能公开的部分"做成可运行的演示，并把**省略了什么、为什么省略**写清楚。

## 一句话

**方法完整可运行，语料与评测集是合成的，生产组件（向量检索、CrossEncoder 重排、业务系统）不在仓库里。**

---

## A. 因合规原因不能公开

| 缺什么 | 为什么 |
|---|---|
| 近两千页 TI TRM 原手册 | 第三方版权文档，体积大；可在 TI 官网自行下载 |
| 14 章 / 17 模块 / 1437 chunks 的生产语料 | 派生于项目工程上下文，属交付内容 |
| 真实评测集（200 题）与标注 | 题目来源于项目真实问题 |
| 领域知识库正文（行业规范、工程模板、命名规范） | 项目方资产 |
| 完整业务平台（文档理解 + 代码生成 + 审查交付） | 含真实工程模块骨架与接口名 |
| 项目名称、机型、内部系统名 | 项目内部约定 |

**这些不是"忘了放"，是刻意拿掉的。** 任何一条拿出来都会构成合规问题。

---

## B. 因体积 / 依赖未包含

| 缺什么 | 原因 | 替代 |
|---|---|---|
| BGE-M3 向量索引（约 2GB 模型 + 索引） | 体积，且需联网下载 | 演示版用字符 n-gram 近似语义通道，融合逻辑一致 |
| CrossEncoder 重排权重（bge-reranker-v2-m3） | 数百 MB | `rerank_gate.py` 用"词覆盖"做轻量近似，**保留按题型开关的判断** |
| 手册 PDF 与抽取产物全量（364 张表） | 体积 | `manual_extraction/out/` 保留少量真实抽取样本 |

---

## C. 演示版做了简化

| 生产版 | 演示版 | 影响 |
|---|---|---|
| 17 个功能模块 | 1 份合成手册、4 个章节组 | 只影响规模，不影响链路 |
| 200 题分层评测 + 3 seed × 120 动态抽样 | 24 题固定演示集 | 指标波动大，只看趋势 |
| 答案级 + 引用行校验 | 只到章节级 | 演示聚焦"检索是否正确" |
| 多路并行 + 元数据过滤 + 模块路由 | 单路两通道 | 路由策略以文档说明为主 |
