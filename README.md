# embedded-rag-demo

**中文提问 → 英文章节式技术手册 → 可溯源的证据定位。**

一个可运行的最小实现：结构感知切片、中英桥、混合检索、条件重排、章节级评测。
它演示的是**方法**，不是完整生产系统（原因见 [docs/03_what_is_missing.md](docs/03_what_is_missing.md)）。

---

## 这个 Demo 想证明什么

技术手册（TRM / datasheet）的知识几乎都压在**寄存器位域表**和**引脚复用表**里。
直接问大模型，它会编位号和复位值；用普通 RAG，中文问句和英文正文的**词表几乎不重叠**，
检索会"语义相近、实体不对"。

这个仓库把三个关键判断做成可运行的代码：

1. **表格被切碎 = 答案必错**。行和表头分离后，块里只有值、没有列语义。
2. **跨语言不是翻译问题，是对齐问题**。中文"输入限定"在英文手册里是 input qualification，
   BM25 命中 0 条；需要中文摘要桥 + 术语别名 + 实体归一化。
3. **重排不是永远有收益**。导航型问题（"在哪一节"）重排会把章节入口压掉，要按题型开关。

## 快速开始

    pip install -r requirements.txt        # 只有 PyMuPDF，检索部分是纯标准库
    python eval/run_eval.py --show         # 章节级检索评测
    python eval/run_eval.py --ablate crosslingual

输出（24 题演示集）：

| 配置 | section@1 | section@3 | hit@5 |
|---|---|---|---|
| 完整链路（中英桥 + 别名 + 归一化） | **83.3%** | 95.8% | 100% |
| 去掉跨语言层 | 45.8% | 54.2% | 75.0% |
| **差值** | **+37.5 pt** | +41.6 | +25.0 |

> 这组数字来自**合成语料 + 24 题演示集**，只用于说明链路作用，不代表任何生产指标。
> 有意思的是它复现了真实项目里的同一个现象：跨语言层缺位时，正确率直接掉一半。

## 仓库结构

    data/manual/            合成手册样本（仿 TI 章节结构，含中英对照段）
    retrieval/
      chunking.py           结构感知切片：按标题层级 + 表格独立成块 + 注入标题/中文摘要
      normalize.py          实体归一化（GPIO12/gpio 12）+ 中英术语别名
      bm25.py               BM25（英文词面）
      hybrid.py             字符 n-gram TF-IDF + BM25 加权融合 + 章节聚合
      rerank_gate.py        条件重排：导航题关闭，事实题按词覆盖重排
    eval/
      run_eval.py           section@1 / section@3 / hit@5 + 消融
      questions.jsonl       24 条演示题（含跨模块题）
    manual_extraction/
      extract_register_tables.py   基于 PyMuPDF 的寄存器表抽取（真实脚本）
      out/                         在真实 TI 手册上跑出来的样本结果

## 关键设计

**1. 切片按结构，不按长度。**
按 `## / ###` 还原 chapter → section 层级；表格整块独立，块内注入小节标题与中文摘要，
保证"这一行属于哪张表"永远不丢。

**2. 中英桥是检索的一部分，不是后处理。**
每个小节带一行 `zh:` 摘要，和英文正文一起进索引。中文问句靠它命中，英文问句靠原文命中。

**3. 字符 n-gram 而不是分词。**
场景是中文 query + 英文正文 + 大量缩写（GPAMUX1、ACQPS、QUALPRD），
字符 2–5 gram 不依赖分词器，也不会把符号切碎。

**4. 融合用加权，不用分数拼接。**
两路量纲不同，各自按最大值归一化后线性融合（alpha=0.6），可解释、可调。

**5. 重排按题型开关。**
导航题直接返回章节入口；事实题用词覆盖做一次轻量重排。生产版这一步是
CrossEncoder（bge-reranker-v2-m3），这里换成无依赖的近似实现。

## 缺什么

这个仓库是**脱敏演示版**：生产语料、评测集与部分组件不在其中。
逐项清单与原因见 [docs/03_what_is_missing.md](docs/03_what_is_missing.md)。

一句话版本：**生产语料（近两千页手册、1437 chunks）、真实评测集（200 题）、
CrossEncoder 重排、向量索引、以及整个上游业务系统，都不在这里。**
